# Radiant Studio feedback

Public bug reports, feature requests, and notes for Radiant Studio.

Open **Issues** to report a bug or request an addition/removal. Please include:
- Your Radiant Studio version and Windows version.
- Exact steps to reproduce the issue.
- What you expected and what actually happened.
- Exact error text and whether the Outliner or a prefab was open.
- Screenshots when useful.

Studio displays public issues in **Bug report / notes > Shared feedback**. GitHub sign-in is needed to submit; reading public feedback does not need a login. Closed issues appear as Completed in Studio.

Local notes and exports are separate. Nothing is automatically uploaded. Do not post passwords, account tokens, or private map files.
